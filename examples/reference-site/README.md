# Saltrum reference site

A one-page site for a fictional four-room guesthouse, built to test the Universal Web Dev routing on a real page. Every name, price, address and tide time is **sample content**; nothing here is a real business.

- Open `index.html` in a browser, or serve the folder: `python -m http.server 8077` from this directory.
- Checks: `python -m unittest discover -s tests -t .` from this directory.
- Plan and status: [sprint plan](docs/sprint-plan.md). Trial findings: [S01 record](docs/sprints/S01.md).

This folder is not installed with the skill; the installer copies only the wrapper files.
